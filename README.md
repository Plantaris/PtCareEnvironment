# PtCareEnvironment

**A 3D First-Person Simulation Environment for Clinical Safety and Ergonomics Training**

This project is part of the *Applied FPS* series — a Unity-based first-person simulation
designed to help Doctor of Physical Therapy (DPT) students and clinicians recognize
safety hazards, ergonomics issues, and best practices in patient care environments.

## 🧩 Core Systems
- Built using **MyFPSCore v1.1** (Keith Hallbourg)
- Modular FPS framework including:
  - Player controller (Cinemachine, FOV, crouch/sprint)
  - Interaction and pickup system (E-key prompt)
  - NPC framework (friendly, neutral, and hostile logic)
  - Door and key systems
  - UI/HUD for health, inventory, and prompts

## 🎯 Current Focus
- Establishing reusable MyFPSCore structure in a clean project
- Testing modular prefabs (Doors, Keys, Weapons, NPCs)
- Preparing for level design focused on **clinical safety scenarios**

## 🧰 Built With
